Frequently asked

PDF kaise upload karu?

Order page par "Start Printing" dabao, drag-drop karo ya "Browse Files" se select karo — PDF ke pages apne aap count ho jaate hain.

Kaunse file formats chalte hain?

PDF, JPG, PNG aur WEBP — ek order me multiple files bhi daal sakte ho.

Price kaise calculate hoti hai?

Pages, copies, print type (B&W/colour), sides aur binding ke hisaab se — total order karne se pehle hi dikh jaata hai.

Selected pages hi print karwa sakte hain?

Haan, page range field me likho jaise 1-5,8,10-12 — sirf wahi pages count hongi.

Order kaise track karu?

Home se "My Orders" kholo — is device se banaye gaye saare orders aur unka status dikhta hai.
